# QuickHealth Pro Max — Interactive Symptom Checker

**A Python fundamentals exercise:** a command-line conversation that asks for basic details and symptoms and responds with general wellness tips, using input handling, conditionals and string formatting.

> **Not medical advice.** This is a programming exercise. It does not diagnose anything. Anyone feeling unwell should speak to a qualified doctor.

## Run

Needs only Python 3 (no packages):

```bash
python main.py
```

## What it practises

- Reading and cleaning user input (`input`, `.strip()`, `.lower()`, `.title()`)
- Branching with `if` / `elif` / `else`
- Formatted output with f-strings
